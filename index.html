01 / The idea

Remember state.
Not just frames.

A current image cannot tell a robot which object was hidden, how many actions it has completed, or which route it saw earlier. SimpleARM keeps this task-relevant history available for control.

01

Decide what to remember

A vision–language model reads the instruction and proposes the identities, progress and procedures that may matter later.

Instruction → memory plan“Pick the container hiding the green cube.”
Watch the cube–container relation.
02

Maintain it with tools

Frozen perception and event tools verify observations and update compact memory as the robot and its surroundings move.

DetectionIdentityOptical flowMasksEventsRoutes
03

Recall when needed

A history-dependent subgoal triggers the relevant read. Memory resolves the referent; current perception locates it for the frozen policy.

Memory → grounded action“The green cube is under this cover.”
Pick that cover in the current view.

Three forms of task state

Entities & relationsWhich object? Under which cover?
Event progressHow many times? Which step next?
Ordered proceduresWhich route? In what order?

The added memory is episode-scoped and training-free. The pretrained grounded-subgoal composer, robot policy and perception models stay frozen.

06 / Conclusion

Remember what matters.
Bring it back to action.

SimpleARM turns interaction history into compact, task-relevant state. A memory plan decides what to retain, frozen tools maintain it as the world changes, and selective retrieval brings it back when a subgoal needs the past.

This simple, training-free memory layer helps frozen robot policies act on identities, progress and procedures that the current image alone cannot reveal.
